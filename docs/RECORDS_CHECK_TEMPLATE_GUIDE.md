# Request for Records Check (PPA Form 13) Template Guide

Template: `templates/RECORDS_CHECK.xlsx`.
Generated by `GET /api/reports/[id]/export/records-check` (Export menu on the report page and the reports list).

## How it works

The workbook has one sheet per agency: **RTC**, **MTCC**, **City Pros**, **PNP-2**, **Brgy**, **NBI**, **Others**. The RTC sheet holds the tagged data cells (E18:E33 and the date); the other sheets reference them with formulas (`=RTC!E18`), which the renderer resolves so every letter shows the same client without recalculation. Office name, the reply address, and the investigating officer are tagged on every sheet.

Any cell containing `{Tag_Name}` is replaced; tags can be moved in Excel. Styles, merges and logos are preserved.

## Tags

| Tag | Source |
|---|---|
| `{Office_Name}` | Office name (header A4 and the reply "TO:" line B43, every sheet) |
| `{Export_Date}` | Date the document is generated |
| `{Name_of_Petitioner}` | FIRST MIDDLE LAST, upper case |
| `{True_Name}` | True name, upper case (falls back to the full name) |
| `{Alias}` | Alias, or `n/a` |
| `{Sex}` / `{Age}` | Sex, age |
| `{Civil_Status}` | Civil status, or `n/a` |
| `{Birthday}` / `{Birthplace}` | Date and place of birth |
| `{Present_Address}` / `{Permanent_Address}` | Addresses (permanent falls back to present) |
| `{Criminal_Case_Numbers}` | Criminal case no. (any typed "Crim. Case No." prefix stripped) |
| `{Offenses}` | Present offense charged with (falls back to convicted of) |
| `{Court}` | Present-offense court (falls back to letter court) |
| `{Spouse_Name}` | Spouse, or `n/a` |
| `{Father}` / `{Mother}` | Parents (two lines), or `n/a` |
| `{Investigating_Officer}` | Prepared-by name, upper case (signature line, every sheet) |

Left as fixed text: office address and contact lines, each agency's "TO:" block, the Chief Probation and Parole Officer line (blank for signature), the reply checklist.

## Adding a tag
1. Type `{New_Tag}` in the cell in Excel (on the RTC sheet, or on every sheet if it is per-letter) and save.
2. Add `New_Tag` to `lib/xlsx/buildRecordsCheckData.ts`.
