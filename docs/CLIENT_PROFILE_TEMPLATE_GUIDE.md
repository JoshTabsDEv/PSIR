# Client's Profile (PPA Form 12) Template Guide

Template: `templates/CLIENT_PROFILE.xlsx`, sheet **Clients Profile**.
Generated by `GET /api/reports/[id]/export/client-profile` (Export menu on the report page).

## How it works

Any cell containing `{Tag_Name}` is replaced with the report value. Tags can be moved to other cells in Excel; the renderer finds them wherever they are. A tag with no value prints as an empty cell, so the officer can fill it by hand. Other sheets in the workbook are left untouched.

Cell styles, merges and logos are preserved. Keep the tag as the only text in its cell (plain text, not a formula).

## Tags

### Header
| Tag | Source |
|---|---|
| `{Office_Name}` | Office name (upper case) |

### Numbers
| Tag | Source |
|---|---|
| `{PI_Number}` | PI No. = Section I "Investigation Docket #" (PI-xxxx-xx-xxxxx) |
| `{PS_Number}` | PS No., the supervision docket (PS-xxxx-xx-xxxxx). If empty, the app asks for it before the first export and saves it on the report. |
| `{Report_Number}` | Internal report number (e.g. `PI-TAG-2026-00001`), not placed on the sheet by default |

### Personal profile
| Tag | Source |
|---|---|
| `{Full_Name}` | LASTNAME, First y Middle |
| `{Alias}` | Alias |
| `{Identifying_Marks}` | Identifying marks |
| `{Address}` | Present address |
| `{Birthday}` | Date of birth |
| `{Birthplace}` | Place of birth |
| `{Age}` / `{Sex}` / `{Civil_Status}` | Age, sex, civil status |
| `{Spouse_Name}` | Spouse |
| `{Educational_Attainment}` | Educational attainment |
| `{Occupation}` | Occupation |
| `{Religion}` | Religious affiliation |
| `{Dependents}`, `{Monthly_Income}`, `{Hobbies}`, `{Skills}` | blank (no field yet) |

### Case details
| Tag | Source |
|---|---|
| `{Criminal_Case_Number}` | Criminal case no. |
| `{Charged_With}` / `{Charged_Date}` | Present offense charged with / date |
| `{Convicted_Of}` / `{Convicted_Date}` | Convicted of / date |
| `{Sentence}` | Sentence |
| `{Judge}` | Present-offense judge (falls back to letter judge) |
| `{Court}` | Present-offense court (falls back to letter court) |
| `{Date_Received}` | Date referral received for PSI |
| `{Date_PSIR_Submitted}` | Date submitted to court |
| `{Custodial_Status}` | On Bail / On Detention / ROR |
| `{Probation_Period}` | Period of probation |
| `{Date_Probation_Granted}`, `{Date_Probation_Order_Received}`, `{Date_Started}`, `{Date_FR_Submitted}`, `{Date_TO_RO}` | blank (no field yet) |

### Signatures
| Tag | Source |
|---|---|
| `{Investigating_Officer}` | Prepared-by name (upper case) |
| `{Supervising_Officer}` | Reviewed-by name, or prepared-by if empty |

The "NOTED" block (Chief Probation and Parole Officer) is fixed text in the template; edit it there.

## Adding a tag
1. Type `{New_Tag}` in the cell in Excel and save.
2. Add `New_Tag` to `lib/xlsx/buildClientProfileData.ts`.
