# Final Report (FR) Template Guide

Template: `templates/FINAL_REPORT.docx`.
Generated by `GET /api/reports/[id]/export/final-report` (Export menu on the report page).

The original "FR- AAA Format.docx" used Word mail-merge fields («Name_of_Petitioner_ALL_CAPS» and so on). Those were converted to docxtemplater tags with the same names, so the layout and formatting are unchanged. Edit the template in Word like the PSIR template: keep each tag as plain text, e.g. `{Judge}`.

## Tags

| Tag | Source |
|---|---|
| `{Office_Name}` | Office name (header) |
| `{Export_Date}` | Date the document is generated (e.g. October 19, 2026) |
| `{Criminal_Case_No}` | Criminal case number |
| `{Violation_For}` | Present offense charged with ("For:" line) |
| `{Name_of_Petitioner_ALL_CAPS}` | FIRST MIDDLE LAST, upper case |
| `{Offense_he_is_convicted}` | Convicted of |
| `{True_Name}` | True name |
| `{Docket_Number}` | PS No., the supervision docket (same value as the Client Profile's PS/PR/PD No.; prompted before the first export if empty) |
| `{Nickname}` | Alias |
| `{Judge}` | Present-offense judge (falls back to letter judge) |
| `{Court}` | Present-offense court (falls back to letter court) |
| `{Address}` | Present address |
| `{in_words}` | blank (date of probation order, no field yet) |
| `{Civil_Status}` / `{Age}` / `{Sex}` | Civil status, age, sex |
| `{Probation_Period}` | Period of probation |
| `{Supervising_Officer}` | Reviewed-by name, or prepared-by if empty, upper case |

Fixed text left as-is: the "Description", "Evaluation" and "Recommendation" narratives, the place line ("Tagbilaran City, Bohol, Philippines"), the "Read and approved by" block.

## Adding a tag
1. Type `{New_Tag}` in Word and save.
2. Add `New_Tag` to `lib/docx/buildFinalReportData.ts`.
